## Backend contract (being finished by someone else right now; code ONLY against this and isolate it in one file)
- `GET /gateway/policy` -> `{document: object|null, pin: {digest, author, approver, approved_at}|null, mode_cap: string|null, digest: string|null}` (the live pinned policy; permission gw.view).
- `GET /gateway/policy/draft` -> `{document, author, saved_at, digest}` | 404 `{detail:"no draft"}` (permission policy.edit).
- `PUT /gateway/policy/draft` body = the policy document -> `{ok:true, digest}` | 422 `{detail:"<message naming target and field>"}` (permission policy.edit).
- `POST /gateway/policy/pin` body `{digest}` -> `{ok:true}` | 409 `{detail:"draft_changed"|...}` | 403 | 428 `{detail:"step_up_required"}` (permission policy.pin; the shared `apiFetch` already opens the step-up dialog and retries once on 428).
- `POST /gateway/policy/reload` -> `{ok:true}` | 409 (permission policy.reload).
Policy document shape: see the schema: `{version:1, mode, targets:{<tag>:{limits:[lo,hi], max_step, max_rate_per_s, min_interval_s, allowed_loop_modes[], hold_off_s, watchdog_s, readback_tolerance}}}`.
